# TP1 - API REST con Spring Boot y DummyJSON

Proyecto desarrollado para la materia **Web II**. Consiste en la implementación de una API RESTful construida con **Spring Boot 4 / Java 25** que integra el catálogo público de [DummyJSON](https://dummyjson.com/) y administra una colección de **Favoritos** persistida en memoria.

---

## 🛠️ Tecnologías y Requisitos Previos

- **Java 25** (o superior)
- **Maven 3.x** (o mediante el wrapper incluido `./mvnw`)
- **Spring Boot 4.1.1**
- **Springdoc-OpenAPI** (Swagger UI)
- **Jakarta Bean Validation**
